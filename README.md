# Member Login & Sign Up System

A sleek, responsive, and user-friendly "Member Login" and "Sign Up" interface built with HTML5 and CSS3. This project provides a clean structure for user authentication forms, including personal detail collection and country selection.

## 🚀 Features

- **Dual Authentication Forms**: Includes both a dedicated Login section and a comprehensive Sign Up form.
- **Detailed Registration**: Collects essential user information:
  - User credentials (Username, Password, Email confirmation)
  - Personal details (First Name, Last Name)
  - Contact information (Email, City, Province, Address)
  - Internationalization support with a Country dropdown.
- **Modern UI/UX**: 
  - Minimalist design with a focus on usability.
  - Responsive layout containers.
  - Interactive buttons with hover States (planned).
- **Clean Codebase**: Organized HTML structure and separate CSS styling for easy maintenance.

## 🛠️ Built With

- **HTML5**: Semantic markup for form structures.
- **CSS3**: Custom styling for tables, inputs, and layout management.
